# **App Name**: Campus Hub

## Core Features:

- Event Listings: Display upcoming campus events with detailed information (time, date, venue).
- Event Search and Save: Allow users to search for specific events and save them for later viewing. Sharing capabilities.
- Club Directory: Explore clubs with filters and categories; also display featured/verified status and include sharing options.
- Notifications Manager: Push event notifications and live updates; allow user configurable options and preferences.
- Calendar & Scheduler: A personalized calendar for each user that includes events that are selected by the user
- Contact and Accessibility: Contact options that provides accessibility details. Auto-routing to a 404 page.
- Sign-Up Tool: A configurable form that saves preferences to the session store. Allows new users to sign up with configurable inputs, and log into an account using e-mail, and remembers details such as name, contact number, DOB, and more.

## Style Guidelines:

- Primary color: Light indigo (#9370DB) for a modern and academic feel.
- Background color: Very light indigo (#F5F0FF) to ensure contrast and readability.
- Accent color: A warm yellow (#FFDB58) to complement the cool indigo, and suggest intellectual discovery.
- Body and headline font: 'Inter', a sans-serif for a modern, neutral look, that works well for both headlines and body.
- Clean and modern icon set. Icons related to calendar, events, clubs, and notifications. Consistency in style across all icons.
- Translucent enlarged headings and layered aesthetics. Extended page lengths to accommodate full content. Consider looping lists for clubs/events.
- Subtle animations inspired by campushackathonconnect.framer.website. Use light radial glow background and effects on illustrations.
